# Repository instructions

## Documentation

- Search for an existing document and update it before creating a Markdown file.
- Create a document only when it fits the taxonomy in [docs/README.md](docs/README.md), and add it to that index in the same commit.
- Record architecture decisions as numbered ADRs.
- Do not add plans, task files, notes, drafts, learnings, or prompts to the repository; put them in the PR description or an issue.
- Link to existing material instead of duplicating it.
- Avoid volatile numbers; link to reproducible evidence.
- Run `npm run check:docs` before committing documentation changes.
