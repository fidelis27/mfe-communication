# Functional Spec — School Secretariat System (multi-MFE)

## 1. Overview

Management system for a school secretariat. Allows registering Institutions
and, within each Institution, registering Students linked to it. The project
is a case study for micro-frontends (MFE) with Module Federation and event
communication — domains are intentionally granular.

Cross-cutting requirement: the system must be ready to scale in data volume,
teams, and domain entities.
